## Как объяснить на защите

1. `position: relative` у области и `position: absolute` у деталей позволяют
   задавать координаты частей гитары внутри рисунка.
2. Корпус собран из двух перекрывающихся округлых псевдоэлементов.
   `border-radius` задаёт форму, `drop-shadow` — тень по силуэту корпуса.
3. Гриф — узкий прямоугольник с градиентом; головка грифа и две половины банта
   получают контур через `clip-path: polygon(...)`.
4. Резонаторное отверстие — круг с границей и радиальным градиентом.
   Струны нарисованы повторяющимся линейным градиентом.
5. Колки создаются псевдоэлементами, а `box-shadow` повторяет их по вертикали.
6. Вся гитара сначала построена вертикально. `transform: rotate(45deg)` на общем
   контейнере поворачивает детали вместе и сохраняет их взаимное расположение.
7. `role="img"` и `aria-label` дают рисунку текстовое описание для скринридера;
   декоративные детали скрыты через `aria-hidden`.
