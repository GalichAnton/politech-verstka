# Задание 1. Верстка сайта

[Условие в ЭИОС](https://dl.spbstu.ru/mod/assign/view.php?id=172883), проверено 5 октября 2026 года.

## Логическая структура

```text
Мой Сосновый Бор
├── Главная: знакомство с городом, даты, фотографии
├── О городе: пять глав истории и источники
├── Места и прогулки: Андерсенград, берег в Липово, собор
└── Практикум
    └── Задание 1: описание реализации и переходы к результату
```

Общее меню связывает основные разделы. Практикум содержит дополнительные
страницы учебных работ. На каждой странице используются общие header, nav,
main и footer. Неизвестный маршрут показывает страницу 404.

## Физическая структура

```text
site/
├── index.html                 # HTML-основа приложения
├── src/
│   ├── main.tsx               # запуск React
│   ├── app/                   # маршрутизация, layout, глобальные стили
│   ├── pages/                 # компоненты страниц
│   ├── widgets/               # шапка и подвал
│   ├── entities/city/
│   │   ├── model/             # тексты, места, метаданные фотографий
│   │   ├── assets/            # пять локальных WebP
│   │   └── ui/                # фотография с подписью и авторством
│   └── shared/ui/             # контейнер, CSS-логотип, заголовок страницы
├── docs/                      # описание работы и источники
└── .github/workflows/         # проверка, сборка, публикация
```

Это React SPA: логическая страница представлена компонентом, а не отдельным
HTML-файлом. После сборки в `dist/` находятся `index.html` и каталог `assets/`
с JavaScript, CSS и изображениями. HashRouter позволяет открывать вложенные
маршруты на статическом хостинге и обновлять их без настройки перенаправлений.

## Соответствие условию

| Требование                                           | Реализация                                                                                                                           |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Произвольная тема и единый стиль                     | Городской гид о Сосновом Боре; общая палитра, типографика и макет.                                                                   |
| Адаптивность                                         | Grid и Flexbox, перенос меню, одноколоночные блоки на узком экране. Табличная верстка не используется.                               |
| Header, footer, контент, меню                        | Общий `AppLayout` для всех маршрутов, включая страницы практикума.                                                                   |
| Дополнительные страницы для заданий                  | `/practice` и `/practice/task-01`. Следующие работы добавляются отдельными маршрутами.                                               |
| Не менее 300 слов и 4–5 картинок вместе              | `/about`: основной рассказ содержит более 300 слов; каждая из пяти глав соседствует с отдельной фотографией.                         |
| Главная наполнена текстом и изображениями            | Вступление, даты, три карточки мест и описание проекта; четыре изображения.                                                          |
| Собственный логотип только средствами CSS, 30–100 px | Силуэт дерева, `clip-path` и псевдоэлементы, размер 48 × 48 px.                                                                      |
| Хостинг                                              | Настроен GitHub Actions → GitHub Pages. Локальные изменения контента попадут на сайт после проверки пользователем и отдельного push. |

## Проверка перед сдачей

```sh
pnpm check
pnpm build
pnpm preview
```

В браузере проверить все маршруты, меню, переходы к главам истории, обновление
вложенной страницы, загрузку фотографий и отсутствие горизонтального скролла
на телефоне. Для подсчёта слов использовать текст абзацев статьи «История
Соснового Бора», без шапки, подвала, источников и подписей фотографий.

Локальная проверка 5 октября 2026 года: `pnpm check` и `pnpm build` завершились
успешно. В production preview подтверждены 481 слово в основном рассказе и
пять изображений на `/about`, загрузка всех фотографий, переходы к пяти главам,
обновление вложенного адреса и отсутствие ошибок консоли. На ширине 360, 768
и 1280 px горизонтального переполнения не обнаружено.

Формат сдачи и оценка преподавателя не зафиксированы: на момент проверки
ответ в ЭИОС ещё не отправлен. Этот документ не является подтверждением защиты.
