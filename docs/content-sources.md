# Источники контента

Проверено 5 октября 2026 года. Город: Сосновый Бор, Ленинградская область.
Текст написан для сайта по перечисленным материалам, без копирования статей.

## Исторические сведения

| Источник                                                           | Что использовано                                                                                                                                                   |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Визитная карточка города](https://sbor.ru/city/visitka)           | География, сохранение сосен и рельефа при строительстве, собор «Неопалимая Купина». Текущие численность населения и расписания из старой страницы не использованы. |
| [Деревня Калище](https://sbor.ru/city/history/kallisa)             | Ижорское население, карта 1676 года, промыслы и стекольное производство XIX века.                                                                                  |
| [Архивная выставка](https://sbor.ru/news?id=18168)                 | Посёлок 1958 года, организации начала 1960-х, статус города 19 апреля 1973 года и ввод первого блока ЛАЭС в декабре 1973 года.                                     |
| [История Андерсенграда](https://sbor.ru/city/history/Andersengrad) | Начало строительства в 1974 году, автор Юрий Тимофеевич Савченко, открытие в 1980 году.                                                                            |

Идеи прогулок и описания визуальных деталей — авторские пояснения к фотографиям,
а не цитаты из путеводителей. Личные воспоминания пользователя не придумывались.
